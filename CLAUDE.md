# CLAUDE.md

This repository uses `AGENTS.md` as the primary, model-neutral coding instructions.

Before making changes:
1. Read `AGENTS.md`.
2. Read the relevant document under `docs/`.
3. Follow the locked stack in `docs/03-technology-stack.md` and layout/naming in `docs/04-repository-layout-and-naming.md`.
4. Follow existing architecture and contracts.
5. Do not introduce PII or weaken security without explicit approval.

When requirements conflict, stop and explain the conflict instead of silently changing security or architecture.
